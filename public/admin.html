⚙️ Cómo funciona CHATTAIKO

Los usuarios se registran y obtienen una API key propia (sk-...).
Cuando hacen una petición, el orquestador elige automáticamente el mejor servicio disponible entre los que configuraste en el .env.
Los usuarios nunca ven tus claves privadas ni saben qué proveedor responde.

Para añadir más servicios: edita el archivo .env, añade la variable (ej: GROQ_API_KEY=gsk_...) y reinicia el servidor.
